## Resume

1. Clone or pull this branch on the home computer. Run `npm ci` at the repository root.
2. Verify with `npm run audit:product-encoding`, `npm run audit:release-seo`, `node scripts/audit-omoikiri-independence.mjs`, `node scripts/test-orders.mjs`, and `node --test tests/tiptop.test.mjs tests/live-prices.test.mjs`.
3. Keep the old `/httpdocs` untouched while preparing a separate Plesk staging copy. The static files alone are insufficient: migrate `/api/*`, D1 data, the stock cron worker, and the Turnstile form check to an independent backend before moving production traffic away from Cloudflare.
4. After end-to-end tests and a fresh backup, switch the web root/site files on the existing Hoster account. No nameserver change is needed if the domain remains on the current IP.

Secrets are not in Git. `.env*`, `.dev.vars*`, and `.wrangler/` are ignored; configure credentials separately on the destination host.
